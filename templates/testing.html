Laboratory Terminal Execution Commands

Commands to run on Windows PowerShell or Command Prompt for your lab exam.

1. Run Full Pytest Suite (Verbose) python -m pytest -v Executes all unit tests and integration tests with detailed pass/fail output.
2. Run Boundary Value Analysis Tests python -m pytest -v tests/test_calculator.py -k "Boundary" Filters and runs only the BVA test suite.
3. Run Pass/Fail Business Logic Tests python -m pytest -v tests/test_calculator.py -k "PassFail" Verifies student passing rules (≥ 35 in each subject).
4. Run Selenium End-to-End Browser Test python tests/test_selenium.py Automates Chrome/Edge browser to fill and verify result submission.
